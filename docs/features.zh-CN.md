# 功能指南

> 0.1 版本实际交付的功能,按面板逐一说明([English version](features.md))。每条一句话与界面里的自描述文案一致。

核心循环:

```
dream 整夜提案 → 你早晨在收件箱一键裁决 → 图谱始终保持可漫游
```

跨面板通例:面板切换即保活(队列页签、分页、选中、滚动位置与图谱相机全部保留);全 UI 的页面引用——收件箱文档的目标页、搜索结果、图谱节点——都在共享页面抽屉里就地打开;抽屉里的「去编辑 →」是唯一的有意跳转。

## 收件箱 —— 裁决台

- **三摞心智**(0.5.0):观点(dream 的观点草稿+判定闭环)、转正(五类信任提升队列)、断案(矛盾+关系提案),另有只读存根摞——仅呈现分组,每条队列保留自己的通道与裁决轨。四层自解释:每摞一句话常驻、空队列写「将来会出现什么」、提升类复制命令自带「为什么是复制命令」(上游 ENG-15,把限制讲成设计)、顶部折叠导览「这是什么?」
- **今天这一摞**(0.5.2):收件箱默认只显示每个来源最新一批待裁决提案(按 `proposed_at` 间隔聚类,批次形状实测钉形),其余收进一个中性样式的安静积压数字,旁常驻一句「提案是流水,不是欠款——留着没有任何代价」;一键展开即回到全量列表,侧栏总数在两种视图下语义不变。**按源静音**(可逆、绝非删除——死账源如从未跑过周期整理的文档导入源)把整源收出默认视图与计数,单独入口随时恢复;**稍后再看**把单条搁置,该来源下次夜间整理跑完自动回来(不做「永不复活」形态;无周期戳的来源如实标注)。批量驳回确认层常驻终局警示「拒绝没有后悔药」,且页面含被藏条目时隐藏批量按钮——任何交互不得把「拿不准」推向拒绝。全部为 cockpit 自有呈现 + 本地状态文件(永不写 gbrain 库)
- **印章不骗人**(0.5.3,走查加固):一键「接受」不再标注 ⌘⌫(该键只绑「驳回」——想用键盘接受的人不会再被按钮上的字引去按出一条不可撤销的驳回);裁决轨所有一键写(盖章、关系标日期/撤销、⌘⌫ 路径)单飞——按钮在途禁用并显示「处理中……」,重入护栏挡住双击与连按的双发;窄于 1240px 的横向导航条恢复显示(CSS 源码顺序 bug 曾让它在任何宽度都不出现——平板/手机/半屏窗口下整个界面没有面板导航)

- **六条队列页签**:信任提案 · 搁置写入 · 待确认事实 · 关系提案 · 观点待判定 · 其他待办——每条队列带一句话自描述;通道不可用时显示「队列暂不可用」而不是误报「空」
- **文档卡 + 裁决轨**:每条待办展开为一份文档,含目标页面、出处与它停在信任链的哪一站
- **三种动作形态,结构固定**:
  - *一键*——驳回 / 接受 / 确认的盖章动作(CLI 白名单或 MCP 通道),大印章落下即是确认时刻
  - *复制命令*——提升信任类动作渲染为命令块加三步指引;裁决只发生在你本人在 brain 主机的终端上(gbrain 安全设计)
  - *降级*——CLI 通道不可用时一键动作自动变成复制命令块;横幅区分两种成因:未找到 gbrain 二进制(本机可能非 brain 主机)与二进制已就位但探测未通过(详见健康面板)
- **通道核查卡**:与代码执行所用的同一份编译期通道矩阵同步渲染——不可能与现实不符
- **批量驳回**一页 takes(两步确认;终端确认类动作永不批量)
- **会话审计块 + 最近裁决表**:每个动作都盖章进固定收据槽位——不弹 toast、不丢记录
- 队列卡片分页,每页条数可选;页面引用(take 出处页、关系/信任目标页)用共享页面抽屉就地打开——正在用的页签、页码与选中不会重置

## 图谱 —— 全脑地图

- brain 里全部页面与全部关系,一张 canvas 地图(sigma.js;标签 canvas 绘制,永不走 HTML)
- 社区分组(Louvain)配色 + 类型化关系颜色 + **关系类型图例,可逐类显示/隐藏**,另有**关系出处分组**(每条关系从哪来——markdown、dream、manual……),计数基于航道所画的同一份边集
- 四种视图:全景 · 聚焦(一页与它的邻居)· 关系矩阵(2 步内邻居分组)· 原版
- 「隐藏低关联页」降噪;待裁决页面始终显示并带标记
- 搜索定位框直达任意 slug;节点抽屉展示类型、关联数、版本数、标签、正反向关系计数与**正文速览**,一键跳去编辑

## 页面 —— 浏览与编辑

- 类型筛选直接来自 brain 自己的 `schema_stats`(不写死任何枚举),带计数
- **三个筛选维度**:类型 facets、slug 前缀输入框(服务端 `slug_prefix` 收窄)与标签输入框(上游 `tag` 筛选——list 行上游不带标签,故为自由输入而非标签 chips);再加来源筛选,全部服务端收窄
- 上游 `offset` 窗口的深度分页——上万页的 brain 每一页都可达,不止第一窗口
- 全写回执协议的在线编辑:乐观锁冲突而非静默覆盖、幂等 request_id、超时轮询收据(绝不重发)
- **写收据区**(懒加载,展开才拉取):gbrain 侧记录的本令牌写请求——状态、request id、slug、时间——外加反复 `source_changed` 冲突页横幅;与会话侧审计表并存的上游真相
- **带完整出处的详情视图**:标签、写入来源(哪个通道写的这页)、创建时间、源文件、信任层级、修订号;**关系**——正向(get_links)与反向(get_backlinks),每条带类型、边级出处与上下文摘录,点击跳转;只读**时间线**;**历史版本**列表。缺失或失败的区块自描述为不可用,不报错
- 页面正文按 markdown 渲染,全站(详情视图、页面抽屉、图谱速览)走同一条 marked → DOMPurify 管线——gbrain 的页面本就是 markdown(仓库即 Markdown 的设计);导入内容属持久化不可信输入:script/图片/表单一律剥离,外链加固(`_blank` + `noopener`)。对话导入包装的页面(引文标记行 + 裹住整个正文的 text 围栏)在渲染时解包;其他形状按原样渲染

## 搜索

- 便宜的字面 + 语义混合入口,前 20 条——不调 LLM
- 顶栏全局搜索框支持 `/` 与 ⌘K;结果带相关度、类型、纯文本摘要与**写入来源徽章**(这页是哪个通道采集的);点击就地速览页面(结果列表保留在原处)
- 每条命中的**证据展开**(assemble_evidence):命中 chunk 周边的文本窗口——整页查看仍归抽屉

## 问一句(0.6)

- 脑子的「回答面」做成**记录仪**:一问一条纸带,按发生的顺序印——问句 → 证据(免费,query,约 2 秒)→ 付费缝 → 在写(36–95 秒,一次整段调用)→ 挂出处的答案 → 缺口。付费腿(think)**每次都是真金白银**:只从两步盖章走(缝上的按钮 + 服务端 confirm 旗标),每脑单飞防连点,每次调用落审计——沿 0.5.1 付费探针先例,但不设管理员门(D5 口令变体同缝可插,零改版切换)
- **出处即奢侈**:答案与缺口句里的每个 [slug] 标记渲染成可悬停小片——带上(实线)悬停浮该证据行的真实摘录、点击跳行琥珀闪烁;脑取(虚线)如实说明「这页是脑子写答案时自读的」并给出「页面」面板出路;仅缺口引用取 `—` 序号;资料附录按引用序全列
- **诚实优先于表演**:等待只有走带动画 + 真实计时(三档文案,阈值来自实测 36–95 秒) + 取消(收据明示「钱可能已花」)——没有进度条、没有 ETA、没有任何假动作。答不出就印「确实有什么 / 缺什么」的诚实卷;think 自报的 gaps[] 原文照录成缺口块
- **降级不出戏**:无钥匙的脑只回证据(「没钥匙」章指向 管理 · 模型接线,永不代配);工具错误按 gbrain 结构化信封直显(code/message/suggestion),官方 `gbrain errors <code>` 查询只复制不代跑
- 答案走 marked → DOMPurify 管线语义(token 树渲染——脑内容里的链接永不变成锚点;全页零 innerHTML);证据摘录按不可信文本原文照排
- 桌脚三件全免费:加宽头部证据(assemble_evidence)、查「为什么缺某页」(query 的 explain_target)、top-K 事实句。query 的付费参数 expand 界面永不出现;think 的 save/take(MCP 忽略的持久化参数)永不发送

## 健康

- **夜间周期卡**(0.5.0):只读旁路的每源周期戳(「跑没跑、多久前」的唯一全源视角)+ doctor 夜间检查集三态行(不适用的检查显式「不适用」,绝不冒充健康;失败痕迹由 sync_freshness/extract_health 承载)+ 每源「现在跑一次校准」复制命令(付费动作,须知随行);周期判定随时刻自然变旧(上游设计 6h 起 warn),时间戳为 UTC。0.5.1:熔断中的付费环节键名就地渲染并配 `dream reset-key` 解锁复制命令;抽取停摆原因计数(限流、计费线索)以「线索」呈现——不做诊断
- **观点校准卡**(0.5.0):判定记分(准确率、Brier)与上游校准档案——有判定之前全为零,如实渲染为空态
- **资产健康卡**(0.5.0):备份覆盖、git 收敛、漏索引、幽灵页——「不是 git 仓库」「未计算」是真实状态不是故障
- **写路径审计**(0.5.0):本令牌的写回执与反复冲突页一处可见
- **部署体检**(0.5.0):脑的检出拓扑 + 生成的逐源两段制单元文本——纯参考材料,附 2026-11-10 破案的坑位注记(repo_path 一钥两锁/systemd 引号/100 页提名窗/评分全脑窗/cron 盲区);cockpit 永不安装、编辑或执行单元

- 总览状态 + 各通道卡片:MCP 延迟仪表、brain 概要(名称、gbrain 版本、引擎、页面数)、CLI 通道(二进制在否)、只读旁路、**来源诊断**(sources_status:克隆状态、最近同步、待写)
- 安全清单:令牌仅走请求头、CLI 白名单纪律、只读旁路固定 SELECT、写入走回执协议
- **源可见性漂移**(0.4.0):旁路看到全库有页面的源,MCP 只见已授权——未授权源一出现即亮出,一键并集补授权(动作时粘贴可选的 `COCKPIT_ADMIN_TOKEN`,绝不持久化)或复制命令降级
- **提案活动 / 周期**(0.4.0):dream 提案轮次时间线 + 上游 `doctor cycle_freshness` 周期判定——如实标注为「活动」而非「dream 运行态」,30/54 小时停摆提示
- **管理页签**(0.4.x,条件可见):部署配置管理档时出现——OAuth 客户端授权一览(只读,cockpit 自己那行高亮)、逐行撤销仅复制命令、补授权入口,以及(0.5.1)**模型接线卡**:当前活跃接线(各档位/各任务实际解析到哪个模型)、哪些服务商钥匙已设(只有布尔,钥匙值绝不进界面)、**当前生效端点**(引擎 config 表 `provider_base_urls.*` 行的固定只读 SELECT——生效端点的唯一结构化正源;owner 批准,值经服务端 URL 校验才出网)、服务商静态检查、一键付费连接测试(`models doctor` 走 dream 同一条装配路径;管理档 step-up、防连点、费用披露),修复指引全部走复制命令并携带 2026-11-12 探针钉死的坑位注记(智谱按量/订阅端点分野、父键寻址坑、env 遮蔽、改配置须重启、熔断解锁)。端点永不预填——由 owner 自己定
- 面向拨测的无鉴权 `/healthz`(只有状态,没有数据)

## 全局

- **中英双语**,首个发布即有:每个面板、动作、空态、错误都带一句话自描述;语言切换按浏览器持久化
- **令牌门**:单一 `COCKPIT_TOKEN`,只存浏览器、只以请求头发送
- **脑切换器**(多 profile 主机):顶栏切换所有调用指向的 gbrain 部署——切换即重挂面板,一个脑的队列绝不渲染成另一个脑的;单 profile 主机不显示切换器
- **来源轴**(联邦 brain):页面、搜索命中、图谱节点与 take 都携带所属源;Pages/Search 按源服务端过滤(只收窄——grant 仍是执法点);图谱可按源着色、跨源关系为虚线;收件箱 take 按源分组
- 键盘快捷:`⌘K` / `/` 搜索 · `⌘⌫` 一键驳回 · `⌘↵` 复制终端命令
- 不可信内容纪律:导入的 brain 内容只经唯一一条 marked → DOMPurify 管线(PageBody)进入 DOM;图谱标签 canvas 绘制,其余一律纯文本
